{% trans "How to update Ravix" %}

{% trans "Updating takes a few clicks. Ravix checks the package, makes a backup, switches to the new version and, if anything goes wrong, goes back to the old version by itself." %}

{% trans "Updates" %}

{% trans "Before you start" %}

{% trans "You do not need to prepare anything: a backup of the files and the database is made automatically before every update. If you want an extra copy of your own, make it first." %}

{% trans "Update from the panel" %}

  1. {% trans "Open Updates in the panel. When a newer version exists, this page and the dashboard show it." %}
  2. {% trans "Read the notes of the new version, then press “Update now”." %}
  3. {% trans "Stay on the progress page or close it. The steps are: download and check, backup, new files, database, switch, restart. The site may show a short maintenance message while it runs." %}
  4. {% trans "When it ends with “Succeeded”, the new version is running. Check the version on the dashboard and open your site." %}

{% trans "Shared hosting (cPanel)" %}

{% trans "The scheduled job (cron) that was set up when you installed Ravix carries out the update, so it can take a minute or two to start. Keep that job active; if it was removed, add it again as the installation guide says." %}

{% trans "Your own server (VPS)" %}

{% trans "A system service does the work in the background; the panel only asks for it. From the command line you can run the installer again from the new version’s folder. It is safe to repeat, and if the new Python packages cannot be installed it changes nothing." %}

sudo bash install.sh --domain example.com --source "$PWD"

{% trans "If something goes wrong" %}

  • {% trans "Failed and rolled back" %} — {% trans "the site is back on the old version with all its data. Open the update to read the reason, fix it and try again." %}
  • {% trans "Failed; manual recovery required" %} — {% trans "wait two minutes: an interrupted update is recovered automatically and ends as rolled back. If it does not, open the update and follow the recovery command shown there." %}
  • {% trans "A maintenance page that stays for a long time: wait a few minutes, then reload. Your data is safe." %}
  • {% trans "Every update keeps its backup, so a manual restore is always possible." %}

{% trans "What an update never replaces" %}

{% trans "Your pages and posts, users, uploaded media, installed themes and plugins, plugin data and the settings file stay as they are." %}

{% trans "After the update" %}

{% trans "Open the site and the panel and check the version on the dashboard. On your own server, run the health check:" %}

sudo -u ravix /srv/ravix/app/deploy/manage.sh ravix_preflight
