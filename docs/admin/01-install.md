# نصب

نصب یعنی سایت را یک بار روی یک سرور (یا کامپیوتر خودتان) راه بیندازید و بعد در مرورگر چند خط اطلاعات بدهید. **اگر «سرور» یا «Docker» برایتان آشنا نیست**، این بخش را به فرد فنی یا پشتیبان میزبانی بدهید؛ بقیهٔ راهنما همه از داخل مرورگر است.

## سه راه
| راه | مناسب | چه لازم دارید |
|---|---|---|
| **آزمایش روی کامپیوتر خودتان** | دیدن سایت بدون هزینه و ریسک | برنامهٔ Docker روی کامپیوتر |
| **سرور اوبونتو** | سایت واقعی با دامنه و قفل امن (HTTPS) | یک سرور اوبونتو ۲۲ یا ۲۴ و دامنه‌ای که به آن اشاره کند |
| **Docker روی سرور** | اگر میزبانتان Docker دارد | Docker و دامنه |

### آزمایش روی کامپیوتر
در پوشهٔ برنامه یک دستور بزنید:
```
docker compose up -d --build
```
بعد در مرورگر `http://localhost/install/` را باز کنید. «کد امنیتی نصب» را این دستور نشان می‌دهد:
```
docker compose exec ravix python manage.py ravix_install_token
```

### سرور اوبونتو
```
sudo ./install.sh
```
خودش همه‌چیز را نصب می‌کند و **پیش از هر تغییر می‌پرسد**. دامنه و ایمیلتان را می‌خواهد (برای گرفتن قفل امن رایگان). اگر خواستید فقط ببینید چه می‌کند: `sudo ./install.sh --dry-run`. اجرای دوباره‌اش بی‌خطر است.

## فرم نصب
اولین باری که سایت را باز می‌کنید به صفحهٔ نصب می‌رسید و این‌ها را می‌پرسد:
- **کد امنیتی نصب** — یک کد که نصب‌کننده چاپ کرده. برای این است که اولین رهگذر اینترنت نتواند سایت شما را تصاحب کند. روی کامپیوتر خودتان لازم نیست.
- **نام سایت**
- **زبان و منطقهٔ زمانی** (پیش‌فرض: فارسی، تهران) — بعداً در «تنظیمات سایت» قابل تغییر است.
- **نام کاربری، ایمیل و رمز** مدیرکل. رمز را قوی انتخاب کنید و جایی امن بنویسید.

با «نصب» وارد پنل می‌شوید و **صفحهٔ نصب برای همیشه بسته می‌شود** (کسی نمی‌تواند دوباره آن را باز کند).

## بعد از نصب
- سایت با یک نوشته و دو صفحهٔ نمونه شروع می‌شود و در داشبورد راهنمای «شروع سریع» می‌بینید.
- **ایمیل:** برای «فراموشی رمز» و خبر دیدگاه‌ها، سایت باید بتواند ایمیل بفرستد. در «سلامت سایت» می‌بینید تنظیم شده یا نه و می‌توانید یک ایمیل آزمایشی به خودتان بفرستید. تنظیم‌کردنش با فرد فنی است.
- **پشتیبان‌گیری** را همین حالا بررسی کنید: [پشتیبان](06-backup.md).
