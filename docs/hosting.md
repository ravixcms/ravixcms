# سازگاری میزبانی

Ravix یک برنامهٔ Django با **فرایند پایدار** (Gunicorn)، **PostgreSQL** و **فایل‌سیستم پایدار و قابل‌نوشتن** است.

## آنچه واقعاً آزموده شده
یک کانتینر لینوکس (Python 3.13، PostgreSQL 16.15، Nginx، Gunicorn، گواهی TLS خودامضا): نصب تمیز، ۱۴ مرحلهٔ بررسی، پشتیبان/بازیابی، ارتقای e2e، آپلود مخرب، سقف حجم.
**هیچ VPS یا میزبان تجاری مشخصی (Hetzner، ParsPack، ابر آروان، …) آزموده نشده.** هر ادعای «سازگار با X» بدون آزمون ساختگی است؛ پیش از انتشار روی میزبان خودتان `ravin_preflight` و `docs/deployment.md` را اجرا کنید.

## آزمون دودی روی سرور شما
`scripts/vps_smoke.sh` مراحل `deployment.md` را روی یک **سرور آزمایشی و تازهٔ** Ubuntu واقعاً اجرا می‌کند و PASS/FAIL می‌دهد. راهنمای دقیق اجرا، متغیرها، خروجی مورد انتظار و جمع‌آوری گزارش: [`vps-smoke-runbook.md`](vps-smoke-runbook.md). اگر سرور تازه نباشد بدون هیچ تغییری متوقف می‌شود.

**وضعیت راستی‌آزمایی:** این اسکریپت **هنوز روی هیچ VPS واقعی اجرا نشده**. فقط نحو، shellcheck، نحو تک‌تک مراحل، رد اجرا روی سرور غیرتازه و تشخیص پشتیبان دست‌کاری‌شده با `backup.sh`/`restore.sh` روی PostgreSQL 16 آزموده شده است. هر میزبان فقط پس از اجرای واقعی در جدول زیر ثبت می‌شود.

## نیازمندی‌ها
| مورد | حداقل |
|---|---|
| سیستم‌عامل | لینوکس با دسترسی root/sudo (Ubuntu 22.04/24.04 مستند شده) |
| Python | Django 5.2 به ≥3.10 نیاز دارد؛ آزموده‌شده: 3.13 |
| دیتابیس | PostgreSQL (تولید). SQLite فقط توسعه/آزمایش؛ تولید آن را رد می‌کند |
| دیسک | پایدار و قابل‌نوشتن برای `media/`، `shop_private/`، `plugins_installed/`، `update_*` |
| فرایند | Gunicorn بلندمدت + Nginx؛ RAM پیشنهادی ≥1GB |
| ابزار | `pg_dump`/`pg_restore` (برای پشتیبان‌گیری) |

## احتمالاً ناسازگار
- هاست اشتراکی cPanel بدون SSH یا بدون Python/PostgreSQL.
- بستر serverless یا فایل‌سیستم زودگذر (Vercel، Lambda، Heroku بدون دیسک پایدار): آپلودها و افزونه‌ها از بین می‌روند.
- چند نمونهٔ وب بدون دیسک مشترک (آپلود، افزونه و کش فایل میان نمونه‌ها همگام نمی‌شود).
