# Ravix Studio — راهنمای کاربر

Ravix Studio صفحه‌ساز بصری Ravix است؛ هم برای **صفحه‌ها** و هم برای **نوشته‌ها**. جایگزین صفحه‌سازِ قدیمی شده است و ویرایشگر کلاسیک (Markdown) همچنان کنارش می‌ماند.

## شروع
- **پنل ← Ravix Studio** یا در فهرست صفحه‌ها/نوشته‌ها دکمهٔ **«ویرایش با Ravix Studio»**.
- ماژول از **افزونه‌ها ← افزونه‌های داخلی** روشن/خاموش می‌شود. اگر مدیر سرور `RAVIX_STUDIO_ENABLED=false` گذاشته باشد، ویرایشگر قفل است ولی صفحه‌های منتشرشده همچنان نمایش داده می‌شوند.

## ویرایشگر تمام‌صفحه
- **وسط:** پیش‌نمایش زنده با قالب واقعی سایت (در iframe). **راست:** ویجت‌ها و لایه‌ها (Navigator). **چپ:** تنظیمات مورد انتخاب‌شده (پایه / پیشرفته / چیدمان).
- ساختار: **بخش ← ستون ← ویجت** (بخش داخلی تا ۳ سطح).
- ویجت‌های مرحلهٔ ۱: بخش، ستون، فاصله، عنوان، متن، تصویر، دکمه، نماد، جداکننده، ویدیو، فهرست نماد، کارت، گالری ساده، نقل‌قول، HTML سفارشی (فقط مدیر)، بخش داخلی، و ویجت‌های افزونه‌ها.
- **اندازهٔ صفحه نمایش:** دسکتاپ/تبلت/موبایل؛ هر مقدار را می‌توان جدا برای هر اندازه تنظیم کرد (خالی = مثل صفحهٔ بزرگ‌تر).
- **ذخیرهٔ خودکار** پس از ~۱٫۵ ثانیه در پیش‌نویس؛ Ctrl+S فوری؛ **واگرد/ازنو** با Ctrl+Z / Ctrl+Shift+Z.
- **صفحه‌کلید:** کلیدهای جهت‌دار در لایه‌ها، Alt+جهت‌دار جابه‌جایی، Enter ویرایش، Delete حذف، Ctrl+D تکثیر. همهٔ کارها بدون موس ممکن است.
- **کشیدن و رها کردن** هم در پیش‌نمایش و هم در لایه‌ها؛ ویجت را با Enter هم می‌توان به ستون انتخاب‌شده افزود.

## ویدیو
یوتیوب، Vimeo، آپارات یا MP4 از کتابخانهٔ رسانه. پخش‌کننده فقط **پس از کلیک** بارگذاری می‌شود (youtube‑nocookie، Vimeo با `dnt=1`). کاور یک بار گرفته و محلی ذخیره می‌شود؛ اگر گرفته نشد، پس‌زمینهٔ ساده نشان داده می‌شود.

## انتشار و تأیید
پیش‌نویس ← «ارسال برای بررسی» ← مدیر «تأیید و انتشار» یا «رد». مجوزها همان نقش‌های قبلی‌اند (`studio.edit`، `studio.publish`، `studio.html`). «لغو انتشار» صفحه را به محتوای کلاسیک برمی‌گرداند.

## نسخه‌ها
هر ذخیرهٔ دستی/انتشار نسخه می‌سازد؛ «بازیابی» نسخه را در پیش‌نویس می‌گذارد و «دوباره زنده کن» نسخهٔ قبلی را منتشر می‌کند. سقف نسخه‌ها `RAVIX_STUDIO_MAX_VERSIONS` (پیش‌فرض ۵۰) است؛ نسخهٔ منتشرشده و نسخهٔ در انتظار هرگز حذف نمی‌شوند.

## ویرایش هم‌زمان
اگر کسی دیگر همان صفحه را باز دارد هشدار می‌بینید. اگر نسخهٔ جدیدتری ذخیره شده باشد، هرگز بی‌صدا بازنویسی نمی‌شود: یا پیش‌نویس او را بارگذاری می‌کنید، یا تغییرات خودتان را نگه می‌دارید (پیش‌نویس او اول به‌عنوان نسخه ذخیره می‌شود).

## درون‌ریزی / برون‌ریزی
صفحه یا یک بخش را به‌صورت JSON خروجی بگیرید و در صفحهٔ دیگر وارد کنید. فایل با schema بررسی می‌شود؛ ارجاع رسانهٔ سایت دیگر پاک می‌شود.

## رسانهٔ حذف‌شده
اگر تصویر یا ویدیو از کتابخانه حذف شود، صفحه خراب نمی‌شود؛ جای آن خالی (امن) می‌ماند.

## مدیر سرور
- `RAVIX_STUDIO_ENABLED` (پیش‌فرض true)، `RAVIX_STUDIO_MAX_VERSIONS` (۵۰)، `RAVIX_STUDIO_INLINE_CSS_MAX` (۵۰٬۰۰۰ بایت؛ بزرگ‌تر از آن CSS به‌صورت فایل hash‌دار در `/studio-assets/css/` سرو می‌شود).
- بعد از به‌روزرسانی که ظاهر ویجت‌ها را عوض می‌کند: `python manage.py studio_rebuild` (با `--all` همه را بازسازی می‌کند). بازسازی تنبل هم هنگام نمایش انجام می‌شود (`RENDERER_VERSION`).
- مسیرهای قدیمی `/panel/builder/` به Studio هدایت می‌شوند. طرح‌های صفحه‌سازِ قدیمی با migration برگشت‌پذیر `studio.0002` بدون از دست رفتن نسخه‌ها وارد شده‌اند.

## امنیت
فقط مقادیر نوع‌دار پذیرفته می‌شود؛ CSS را سرور از روی تنظیمات می‌سازد (هیچ CSS خامی از کاربر نمی‌آید)، HTML با nh3 پاک می‌شود و HTML سفارشی فقط برای مدیر است.
