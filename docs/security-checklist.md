# چک‌لیست امنیت پیش از انتشار

با ✔ علامت بزنید. بندهای «خودکار» را `python manage.py ravin_preflight` و `check --deploy` می‌سنجند.

## پیکربندی (خودکار + دستی)
- [ ] `DEBUG` خاموش؛ `DJANGO_SECRET_KEY` تصادفی ≥۵۰ نویسه و فقط در `/etc/ravin/ravin.env` (مجوز 640)
- [ ] `DJANGO_ALLOWED_HOSTS` فقط دامنه‌های واقعی؛ `DJANGO_CSRF_TRUSTED_ORIGINS` با `https://`
- [ ] PostgreSQL با رمز قوی؛ پورت 5432 از اینترنت بسته (`ufw status`)
- [ ] HTTPS فعال و `certbot renew --dry-run` موفق؛ HSTS فعال
- [ ] `ravin_preflight` بدون خطا و `manage.py check --deploy` بدون مشکل
- [ ] ایمیل SMTP واقعی تنظیم و یک ایمیل آزمایشی ارسال شد (بازیابی رمز)
- [ ] فایل `.env` و پشتیبان‌ها در مخزن کد نیستند (`.gitignore`)

## حساب‌ها
- [ ] مدیرکل با رمز قوی و یکتا؛ حساب‌های آزمایشی/پیش‌فرض حذف شده‌اند
- [ ] ثبت‌نام عمومی در صورت نیاز نبودن خاموش است (تنظیمات سایت)
- [ ] نقش‌ها بازبینی شد: فقط افراد لازم «مدیر» هستند

## فروشگاه
- [ ] `RAVIN_SHOP_ALLOW_SANDBOX_IN_PRODUCTION=false` (یا فروشگاه خاموش)، و **درگاه واقعی فقط با آداپتور آزموده‌شده**
- [ ] تأیید پرداخت سرور-به-سرور در آداپتور واقعی (نه اعتماد به پارامتر بازگشت) و برابری مبلغ
- [ ] یک خرید آزمایشی با مبلغ کم در محیط واقعی درگاه، شامل پرداخت ناموفق و لغو
- [ ] تایمر `ravin-expire-orders.timer` فعال است
- [ ] سیاست بازپرداخت/مرجوعی تعریف شده (سیستم بازپرداخت خودکار ندارد)

## افزونه‌ها
- [ ] فقط افزونه‌هایی که کدشان بازبینی شده نصب‌اند؛ پوشهٔ `plugins/` برای کاربر سرویس فقط‌خواندنی
- [ ] `RAVIN_PLUGINS_SAFE_MODE` و کلید `RAVIN_PLUGINS_ENABLED` را می‌شناسید (بازیابی اضطراری)

## نصب‌کنندهٔ افزونه
- [ ] `RAVIN_PLUGIN_WEB_INSTALL` فقط اگر لازم است روشن است؛ `plugins/` پروژه فقط‌خواندنی و فقط `RAVIN_PLUGIN_INSTALL_DIR` قابل‌نوشتن است
- [ ] `RAVIN_TRUSTED_PUBLIC_KEYS`/کلیدهای پنل فقط ناشران شناخته‌شده را دارد؛ کلیدها از کانال مستقل گرفته شده‌اند
- [ ] `RAVIN_PLUGINS_ALLOW_UNSIGNED=false`؛ کلید امضای مخزن (اگر مخزن دارید) در فایل 600 خارج از مخزن کد است و پشتیبان امن دارد
- [ ] قبل از ارتقای افزونهٔ دارای مدل، پشتیبان دیتابیس گرفته شد؛ پوشهٔ `plugin_backups` پشتیبان‌گیری می‌شود
- [ ] مدیران می‌دانند امضا ≠ بی‌خطر بودن کد و کد را پیش از تأیید می‌بینند

## چندسایتی (اگر روشن است)
- [ ] هر دامنه فقط به یک سایت اشاره می‌کند؛ هر کاربر فقط عضو سایت‌های لازم است
- [ ] با دو حساب آزمایشی تأیید شد که داده سایت دیگر دیده نمی‌شود

## زیرساخت
- [ ] `ufw` فعال (22/80/443)؛ ورود SSH با کلید و بدون رمز؛ به‌روزرسانی‌های امنیتی خودکار (`unattended-upgrades`)
- [ ] پشتیبان روزانه + نسخهٔ آف‌سایت + **بازیابی آزمایشی موفق**
- [ ] مانیتورینگ ساده روی `/healthz`؛ لاگ‌ها در journald بازبینی می‌شوند (`journalctl -u ravin`)
- [ ] Nginx: `client_max_body_size`، محدودیت نرخ ورود/پرداخت (در `deploy/nginx-ravin.conf`)، `/media/` بدون اجرای اسکریپت

## آنچه این چک‌لیست جایگزین نیست
تست نفوذ مستقل، بازبینی حقوقی/مالیاتی فروشگاه، و بررسی الزامات درگاه پرداخت و نماد اعتماد در ایران.
